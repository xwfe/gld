上一个发布版是 v0.4.0；0.5.0、0.6.0 没有单独发版，改动都在这一版里。

## 从 v0.4.0 升上来：先看这一条

**只剩一个服务了**（0.6.0，[RFC-0004](https://github.com/xwfe/gld/blob/main/docs/rfc/0004-one-service-many-projects.md)）。以前一个项目一个
MCP 服务、一条地址；现在所有项目挂在同一个服务下，客户端只配一条地址，AI 调用时用 `workspace`
参数选项目。

升级后 `gld daemon restart` 会停掉旧的单项目服务，它们不会再回来。在任意项目目录里执行一次
`gld start`：服务起来，登记过的项目都会加进去（输出里逐个点名）。**客户端要改连服务的地址**
（`gld ls` 里那一行）；ChatGPT 的连接器改不了地址，只能删了重建。

命令也改成了顶层一个词：`gld add` / `gld rm` / `gld ls` / `gld set` / `gld share` / `gld upgrade`。
旧的 `ws`、`hub`、`tunnel` 等还能敲，只是不进帮助。

## 从 0.6.x 升上来

换二进制、`gld daemon restart`，Client ID、授权口令、ChatGPT 的授权都不用动。守护进程协议从 3
升到 4：换完没重启时命令行会报"守护进程版本不一致"（退出码 4），重启就好。这一版给工具加了参数，
ChatGPT 要到 chatgpt.com/plugins 打开 gld 这条连接点一次 **Refresh**，再开新对话。
完整步骤和换完怎么核对见[安装 · 升级](https://github.com/xwfe/gld/blob/main/docs/install.md#升级)。

## 这一版（0.7.0）的主要变化

- **任务要有证据才算完成**：`finish` 带 `evidence_session_ids`，只收任务期间用 `exec_command`
  跑过、退出 0、之后没再改过文件的命令；暂停的任务不放行写入。
- **命令失败如实记账**：Planning 台账、操作记录、任务事件按命令终态记 `failed` / `running` /
  `timed_out` / `cancelled`，不再把"调用返回了"记成完成。
- **外部改动之后能恢复**：`refresh_baseline` 先列出变了哪些文件，看过、写明原因再接纳。
- **任务存储经得起并发和坏文件**：两个客户端同时开任务只会开成一个；任务文件坏了停写并报
  `STORE_CORRUPT`，日志坏行逐行报出、后面的照读。
- **`git_diff` / `git_show` 的文件清单直接问 git**：每个文件一条，真实状态，改名带原路径，
  标出二进制和是否已暂存。
- **本机 MCP server 的结构化结果不再被丢掉**；命令输出过期时说明"已经执行过、只是输出取不回"，
  不再叫人直接重跑。
- **核对客户端拿到的工具表**：`gld tool list --served` 看服务实际发出去的表，`server_info` 报
  构建提交。
- **支持 MCP 2026-07-28 的客户端照常能连**：ChatGPT 连接器和官方 SDK 先探测新协议，gld 回
  "没有这个方法"，它们退回 2025-06-18 连上（ChatGPT 和官方 TS SDK 2.0 实测过）。

0.5 / 0.6 还加了：本机装好的 MCP server 经服务转给 AI、Skills 与附件、按 cell 读写 Jupyter
notebook、补丁的文件版本前置条件（不盖掉读之后别人的改动）、按目录和跨进程的写锁、命令会话按
调用方分开、超长行的续读、参数名写错直接报错。

## 可能影响你的行为变化

- 任务进 `completed` 只能经 `finish` 带证据；公开的状态迁移直达 `completed` 报 `VERIFICATION_REQUIRED`。
- 没有没结束的任务、却有任务文件读不出来时，写工具和开新任务报 `STORE_CORRUPT`，要先修好或挪开那个文件。
- `git_diff` 的 `files` 多了 `staged`、`old_path`，状态不再一律是 `modified`。
- 工作区里名叫 `build`、`dist`、`target` 这类的**文件**开始计入任务指纹（只有同名**目录**不计）：升级前开的
  任务第一次写入可能报 `FILE_CHANGED_EXTERNALLY`，用 `refresh_baseline` 看过后接纳。

## 下载校验

每个包旁边有 `SHA256SUMS`：

```bash
shasum -a 256 -c SHA256SUMS      # Linux 上是 sha256sum -c SHA256SUMS
```
