## 从 v0.7.0 升上来

换二进制、`gld daemon restart`。Client ID、授权口令、签名密钥、ChatGPT 注册的客户端都不动，连接器不用删、
不用重新授权。

- **ChatGPT 要点一次 Refresh**：`exec_command`、`apply_patch`、`patch_check`、`check_command` 的 `confirm`
  参数说明改了，工具表跟着变。到 chatgpt.com/plugins 打开 gld 这条连接点 **Refresh**，再开新对话；
  不点照常能用，只是看不到新说明。工具个数没变。
- **守护进程协议 4 → 5**：换完没重启时命令行报"守护进程版本不一致"（退出码 4），重启就好。

完整步骤、升级前后怎么比工具表指纹见[安装 · 升级](https://github.com/xwfe/gld/blob/main/docs/install.md#升级)。

## 这一版（0.8.0）的主要变化

- **只开几个项目的凭据：`gld grant`**。`gld grant add <名字> <项目>…` 发一把自带口令（OAuth 授权页用）和
  令牌（bearer 用）的凭据，默认只读，`--write` 才能写。用它进来的连接只看得到开给它的项目；`gld grant rm`
  下一次请求就生效，并停掉它起的命令。能写的 grant 等于能以你的身份跑任意命令，给别人的只能是只读的。
  用法和边界见[概念 · 只开几个项目](https://github.com/xwfe/gld/blob/main/docs/concepts.md#只开几个项目gld-grant)。
- **命令的运行记录落盘，gld 重启后照样读得到**：每条 `exec_command` 的结局和 stdout / stderr 各最后 2 MiB 留在
  `~/.config/gld/runs/`。守护进程重启、被 `kill -9`、直连模式下换了一条命令行，`read_output` 都能读到结局，
  不再报 `SESSION_NOT_FOUND`。gld 退出时停掉的记 `interrupted`，gld 来不及记的记 `unknown`。
  不恢复进程；重启前跑完的测试不能当任务验收证据，要重跑。
  见[概念 · 命令的输出能读多久](https://github.com/xwfe/gld/blob/main/docs/concepts.md#命令的输出能读多久stdin-怎么关)。
- **不再留孤儿进程**：`gld daemon stop` / `restart` 时停掉所有还在跑的命令（以前经 `gld tool call` 起的会留下）；
  直连模式下命令行退出前停掉自己起的命令。拦着 TERM 的 1.5 秒后补 KILL。
- **安全说法照实**：`request_permissions` 任何模式都不再回 `granted`；`confirm` 参数写明服务端核实不了
  用户有没有批准；退役把能写的工具标成只读的 `compat-readonly-all`。
- **改全局设置（比如可执行路径）后立刻生效**：以前 `gld tool call` 要重启守护进程才用上。
- **每个下载包带构建来源证明**：`gh attestation verify` 能验它是这个仓库的发布流水线编的，
  做法见[安装](https://github.com/xwfe/gld/blob/main/docs/install.md#下载现成的不需要装-rust)。

## 可能影响你的行为变化

- 配置里写着 `compat-readonly-all` 的，升级后读成 `advanced`：工具一个不少，但标注照实，客户端会开始在
  改文件、跑命令前问你。`gld set` / `gld upgrade` 再给这个值会报错。
- **项目是某个仓库的子目录时，Git 工具只看这个子目录**（所有凭据都一样）：`git_status` / `git_diff` /
  `git_log` / `git_show` 不再列兄弟目录的东西；`git_show` 的 `rev` 写 `HEAD:别的目录/文件` 报
  `PATH_OUTSIDE_WORKSPACE`；路径过滤不能以 `:` 开头。项目就是仓库根的不受影响。
- 被 `kill_session` 停掉、结束超过 5 分钟、守护进程重启过的命令，`read_output` 回的是记录里的结局
  （回包带 `source: "run_record"`），不再是 `SESSION_EXPIRED` / `SESSION_NOT_FOUND`。
  `termination_reason` 多了 `interrupted` 和 `unknown`。
- 守护进程退出时经服务起的命令以前记 `killed`，现在记 `interrupted`。
- 数据目录多了 `runs/`：命令输出原样落盘、**不脱敏**，每个项目留最近 64 条、最长 7 天，最坏 256 MiB。
- 有 grant 时 `gld upgrade --auth noauth` 报错。
- GPT Actions 线路上调 `request_permissions` 不再有 `granted`。

## 退回 0.7.0

换回旧二进制、`gld daemon restart` 即可。数据文件里多出的 `grants` 键和 `runs/` 目录旧版本会忽略；
grant 发出的令牌在旧版本上一律 401，不会被当成全权令牌。

## 下载校验

每个包旁边有 `SHA256SUMS`：

```bash
shasum -a 256 -c SHA256SUMS      # Linux 上是 sha256sum -c SHA256SUMS
```

核对包是这个仓库的发布流水线编的（要装 GitHub CLI）：

```bash
gh attestation verify gld-v0.8.0-aarch64-apple-darwin.tar.gz --repo xwfe/gld \
  --signer-workflow xwfe/gld/.github/workflows/release.yml
```

macOS 和 Windows 的包没有代码签名，第一次运行会被 Gatekeeper / SmartScreen 拦，处理办法见
[安装](https://github.com/xwfe/gld/blob/main/docs/install.md#下载现成的不需要装-rust)。
