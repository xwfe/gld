## 从 v0.8.3 升上来

换二进制、`gld daemon restart`，步骤见[安装 · 升级](https://github.com/xwfe/gld/blob/main/docs/install.md#升级)。连接器不用删，也不用重新授权。

- **ChatGPT 要点一次 Refresh**：工具表多了 `agent_manage`、`prompt_manage`，没有删工具。到 chatgpt.com/plugins 打开 gld 这条连接点 Refresh，再开新对话；不点照常能用，只是看不到新工具。
- **守护进程协议从 5 变成 16**：换完没重启时命令行报版本不一致（退出码 4），重启就好。
- **这次重启仍然会断片刻**：这一版起有命令在跑时 `gld daemon restart` 不重启、先列出来，确定要停加 `--force`。

## 这一版的变化

- **工具进子进程（实验）**：`gld daemon run` 拿着端口、隧道、OAuth 和配置，工具和命令在子进程里跑。子进程挂了服务还在，会自动起新的，正在跑的那次调用报 `generation_lost`。见 [RFC-0008](https://github.com/xwfe/gld/blob/main/docs/rfc/0008-continuous-upgrades.md)。
- **`gld daemon upgrade`（实验）**：不重启换工具实现，有 `status`、`prepare`、`switch`、`abort`。**这还不是零中断**：已经用过的项目不换版本，服务本身的代码换不了。Windows 上没跑过。见[安装 · 不重启换工具实现](https://github.com/xwfe/gld/blob/main/docs/install.md#不重启换工具实现)。
- **把活委派给本机 Agent**：`agent_manage`、`gld agent`，项目开关 `agent-delegation`，默认关。内置档案里只有 codex 真跑通过。
- **原生节点（实验）**：另一台机器装 gld 后主动连回 Hub，一条连接操作多台机器的项目：`gld node invite`、`gld join`、`gld node run`、`gld leave`。只在一台 Linux 服务器上冒烟过，安装接入还要手工拼命令。
- **不属于项目的任务空间**：`work_session`，默认关。
- **按项目放行全部命令**：`gld set <项目> command-policy=all`。
- **只能填 URL 的浏览器扩展**：`gld grant browser`。
- **OpenAI Secure MCP Tunnel**：`gld share --tunnel openai:<隧道 ID>`，没连过真隧道。
- **按需读 Prompt**：`prompt_manage`，读 `~/.agents/prompts` 和项目的 `.agents/prompts`。
- **Skill**：认 Claude Code 开着的插件带的 skill，`list_skills` 能按词查。
- **`read_file` 的 `ranges`**：一次读几个文件、几段行。
- **`gld prune`**：清掉目录不在了的项目和已删项目的残留。
- **补丁失败留下原因**：请求日志记 `[patch]` 行。
- **`gld --version` 带构建提交**。
- Cloudflare Tunnel Token 不再进命令行参数。

## 可能影响你的行为变化

- 多一个进程：`ps` 里能看到 `gld daemon generation`，`gld daemon status` 报的 pid 还是主进程。
- 守护进程被 `kill -9` 时，它起的命令不再成孤儿，子进程收好再退，记录是 `interrupted`。只杀子进程时命令才成孤儿，记录是 `unknown`。
- `--write` grant 现在能委派 Agent，Agent 是全权跑的，发给谁要想清楚。

## 退回 0.8.3

换回旧二进制、`gld daemon restart`。ChatGPT 若已刷新过工具表，再点一次 Refresh。Hub 连过开了 `--run` 的目标机之后，要连数据目录一起回退，见[安装 · 升级](https://github.com/xwfe/gld/blob/main/docs/install.md#升级)。

## 下载校验

每个包旁边有 `SHA256SUMS`：

```bash
shasum -a 256 -c --ignore-missing SHA256SUMS    # Linux 上是 sha256sum -c --ignore-missing SHA256SUMS；只核你下了的包
```

核对包是这个仓库的发布流水线编的（要装 GitHub CLI）：

```bash
gh attestation verify gld-v0.9.0-aarch64-apple-darwin.tar.gz --repo xwfe/gld \
  --signer-workflow xwfe/gld/.github/workflows/release.yml
```

macOS 和 Windows 的包没有代码签名，第一次运行会被 Gatekeeper / SmartScreen 拦，处理办法见[安装](https://github.com/xwfe/gld/blob/main/docs/install.md#下载现成的不需要装-rust)。
